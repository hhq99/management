
一、氛围诊断
| 领域 | 关键词 | 问卷题目 |
|------|--------|----------|
| 业务发展 | 定位、业务价值 | 我会在会议上、平时沟通以及考评沟通时，传递团队的定位、业务价值和信心，员工对这些也都很清楚 |
| 业务发展 | 业务认同感 | 员工认同团队的定位、业务价值，对我们团队能做出价值、取得好成绩看好 |
| 业务发展 | 业务认同感 | 员工能够感受到团队内其他员工对能够做出价值、取得好成绩看好 |
| 个人发展 | 组内机会 | 团队内的工作设置和安排比较灵活，员工在我们的团队能够得到他们期望的锻炼机会 |
| 个人发展 | 能力发挥 | 员工承担的工作有助于能力拓展或提升，目前团队成员从事的工作是他（她）愿意或喜欢的 |
| 个人发展 | 能力发挥 | 员工目前承担的工作与他（她）的长远打算是一致的 |
| 个人发展 | 价值感 | 对目前的工作或承担的职责，员工认为在团队中很重要、很有价值 |
| 个人发展 | 团队认同感 | 员工觉得在我们的团队，只要用心付出就不担心后面的绩效评价和相关回报 |
| 组织运作 | 工作安排合理性感受 | 员工觉得组内的职责分工与设置、流程协同等合理、顺畅，内部组员协同效率好 |
| 组织运作 | 配合顺畅感受 | 员工感觉与周边配合顺畅、流程清楚，互相推诿很少 |
| 绩效导向、评价与激励 | 目标清晰度 | 我会花时间与员工沟通工作职责、PBC和工作重点，帮助员工清晰理解目标、工作要求和当前工作对团队的价值 |
| 绩效导向、评价与激励 | 绩效导向清晰度 | 我会花时间和团队一起明确绩效导向，确定工作输出的评价标准，团队导向清晰、评价标准清楚，团队成员认同 |
| 绩效导向、评价与激励 | 能力建设认可度 | 我会与团队成员一起结合工作目标和任职发展，制定能力提升举措，团队成员认同 |
| 绩效导向、评价与激励 | 内部知识管理认可度 | 我关注组内的知识管理和建设，帮助团队成员获得必要的资源（文档、工具等）更高效完成工作，团队成员认同 |
| 绩效导向、评价与激励 | 主管辅导认可度 | 当员工有需要时，我能及时帮助员工排忧解难（启发思路、提供帮助、协调资源等），帮助员工突破障碍 |
| 绩效导向、评价与激励 | 及时反馈感受 | 我能够及时肯定员工的成绩和贡献，同时也能具体地反馈员工需要改进的地方 |
| 绩效导向、评价与激励 | 绩效评价感受 | 我会结合团队绩效导向给员工反馈、表扬及评价，包括内部的一些小奖励，组员认同我的反馈、表扬和评价 |
| 绩效导向、评价与激励 | 绩效规范性 | 我在做绩效管理的时候，公司的基础流程和动作如目标制定、辅导、评价、沟通等都不会有遗漏 |
| 绩效导向、评价与激励 | 绩效客观性感受 | 团队成员认为得到的绩效结果符合实际贡献 |
| 绩效导向、评价与激励 | 绩效沟通感受 | 我会与团队成员充分沟通评价结果，并指出工作的优缺点和建议，沟通过程能互相交流，甚至互相激发 |
| 内部氛围 | 团队认同感 | 我们团队内部彼此能坦诚说话，没太多顾忌，例如，平时、开会的时候，大家都能积极说出自己的想法和建议 |
| 内部氛围 | 主管认可度 | 我一般会放手让大家去做事情，出了错误更多的是引导而不是责难，大家对我很信任 |
| 内部氛围 | 主管认可度 | 团队成员和我能袒露自己的内心想法和诉求，我会与团队成员定期或不定期的谈比较深入的话题，说一些心里话 |
| 内部氛围 | 主管认可度 | 在员工表现突出或取得成绩时，我能够及时肯定或激励，团队成员能感受到自己很受关注 |
| 总体 | 团队认同感 | 我们的团队成员乐于相互协作支撑，团队战斗力高昂 |
