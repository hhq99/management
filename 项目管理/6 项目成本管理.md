## 一、章节核心概念

项目成本管理包括为使项目在批准的预算内完成而对成本进行规划、估算、预算、融资、筹资、管理和控制的各个过程。

**考试核心要点：**

- 重点关注**完成项目活动所需资源的成本**
  
- 同时需考虑项目决策对产品使用成本、维护成本和支持成本的影响（即全生命周期成本）
  
- **成本管理计划本身不产生成本**，只是描述如何管理成本的指南
  

## 二、过程1：规划成本管理（规划过程组）

**定义**：确定如何估算、预算、管理、监督和控制项目成本的过程

**主要作用**：在整个项目期间为管理项目成本提供指南和方向

### 核心输出：成本管理计划（重点！）

成本管理计划描述将如何规划、安排和控制项目成本，包含以下内容：

|     |     |
| --- | --- |
| 内容  | 说明  |
| **计量单位** | 如人天、人时、米、升、吨等 |
| **精确度** | 成本估算取整的程度 |
| **准确度** | 为活动成本估算规定可接受的区间 |
| **组织程序链接** | WBS为成本管理提供框架 |
| **控制临界值** | 在需要采取措施前允许出现的最大差异，通常用偏离基准的百分数表示 |
| **绩效测量规则** | 规定挣值管理(EVM)规则 |
| **报告格式** | 规定成本报告的格式和编制频率 |

**考试提示**：成本管理计划是项目管理计划的组成部分，它本身不是一个预算文件，而是“如何管钱”的指南。

## 三、过程2：估算成本（规划过程组）

**定义**：对完成项目活动所需货币资源进行近似估算的过程

**主要作用**：确定项目所需的资金

### 估算精度（高频考点！）

> 估算准确性随项目进展逐步提高

**输入**：WBS、项目进度计划、事业环境因素。

### 核心工具与技术（必考！）

|     |     |
| --- | --- |
| 工具  | 说明  |
| **类比估算** | 使用类似项目的历史数据，速度快，准确性较低 |
| **参数估算** | 使用统计关系和变量数据（如工作小时数×小时费率） |
| **自下而上估算** | 从工作包逐层向上汇总，**最准确** |
| **三点估算** | 贝塔分布：期望值=(乐观+4×最可能+悲观)/6<br><br>标准差：σ=(cP-cO)/6<br><br>方差：σ2=[(cP-cO)/6]2 |
| **储备分析** | 分析应急储备和管理储备 |
| **质量成本(COQ)** | 包括一致性成本和非一致性成本 |

### 储备分析（高频考点！）

- **应急储备**：包含在成本基准中，项目经理有权使用，用于应对已识别的风险。随着信息明确可动用、减少或取消
  
- **管理储备**：不包含在成本基准中，用于应对未知-未知风险。，但属于项目总预算的一部分，不能直接使用。
  

### 输出

- **成本估算**：包括完成项目工作可能需要的成本
  
- **估算依据**：清晰说明估算如何得出，包括假设条件、制约因素、估算区间、置信水平等
  

## 四、过程3：制定预算（规划过程组）

**定义**：汇总所有单个活动或工作包的估算成本，建立经批准的成本基准的过程

**主要作用**：确定可据以监督和控制项目绩效的成本基准

### 核心公式（必记！）

**项目预算 = 成本基准 + 管理储备**

### 关键概念辨析（高频考点！）

|     |     |
| --- | --- |
| 概念  | 说明  |
| **成本基准(BAC)** | 经批准的、按时间段分配的项目预算，**包含应急储备，不包含管理储备** |
| **管理储备** | 不包含在成本基准中，属于项目总预算的一部分 |
| **项目资金需求** | 成本基准 + 管理储备 |
| **应急储备** | 包含在成本基准中，项目经理可动用 |

### 工具与技术

- **成本汇总**：从工作包→控制账户→项目总成本，逐层累加
  
- **历史信息审核**：用于类比估算和参数估算
  
- **资金限制平衡**：根据资金限制调整工作进度计划，平衡资金支出
  

配套常用缩写：

1. PV：Planned Value 计划值
  
2. EV：Earned Value 挣值
  
3. AC：Actual Cost 实际成本
  
4. BAC：Budget At Completion 完工预算
  
5. EAC：Estimate At Completion 完工估算
  
6. ETC：Estimate To Complete 完工尚需估算
  
7. VAC：Variance At Completion 完工偏差
  
8. CPI：Cost Performance Index 成本绩效指数
  
9. SPI：Schedule Performance Index 进度绩效指数
  

## 五、过程4：控制成本（监控过程组）

**定义**：监督项目状态，以更新项目成本和管理成本基准变更的过程

**核心目的**：分析资金的支出与完成工作是否匹配

### 挣值管理(EVM)——考试重中之重！

#### 三大核心指标（必背！）

|     |     |     |
| --- | --- | --- |
| 指标  | 公式  | 含义  |
| **PV**（计划价值） | 计划工作量 × 计划单价 | 到目前计划做多少 |
| **EV**（挣值） | 实际工作量 × 计划单价 | 到目前实际做了多少 |
| **AC**（实际成本） | 实际工作量 × 实际单价 | 到目前实际花了多少 |

#### 偏差分析（必考！）

|     |     |     |
| --- | --- | --- |
| 指标  | 公式  | 判断  |
| **CV**（成本偏差） | EV - AC | >0 成本节约；<0 成本超支 |
| **SV**（进度偏差） | EV - PV | >0 进度提前；<0 进度落后 |

#### 绩效指数（必考！）

|     |     |     |
| --- | --- | --- |
| 指标  | 公式  | 判断  |
| **CPI**（成本绩效指数） | EV / AC | >1 成本节约；<1 成本超支 |
| **SPI**（进度绩效指数） | EV / PV | >1 进度提前；<1 进度落后 |

> **记忆口诀**：所有指数都是 **EV 在上边**

#### 预测技术（高频计算题！）

|     |     |     |     |
| --- | --- | --- | --- |
| 指标  | 公式  | 适用场景 |     |
| **ETC**（完工尚需估算） | 自下而上估算 | 重新估算剩余工作 | 典型偏差 (BAC - EV)/CPI |
| **EAC**（完工估算） | AC + ETC | 基本公式 | <br> |
| <br> | AC + (BAC - EV) | **非典型**偏差（偏差不会持续） | - 情形 1：现在偏差属于特例，后续工作按原计划执行：<br> <br>- **BAC-CV** |
| <br> | AC + (BAC - EV)/CPI | **典型**偏差（偏差会持续） | <br> |
| <br> | **BAC / CPI** | 典型偏差的简化形式 | 场景：当前超支是常态问题，后面工作也会按同样浪费比例花钱 例：一直用料浪费，后续不会改善，整体成本按当前 CPI 推算。<br><br>项目 BAC=100 万，做到一半： AC=60 万，EV=40 万，CPI=40/60≈0.67 属于典型偏差，后续成本控制不会好转EAC=100÷0.67≈150万 含义：按现在花钱速度，整个项目全部完工预计总共要花 150 万。 |
| **TCPI**（完工尚需绩效指数） | (BAC - EV)/(BAC - AC) | 剩余工作÷剩余资金，**越小越好** | <br> |
| **VAC**（完工偏差） | BAC - EAC | 预测完工时的成本偏差 | <br> |

**考试提示**：题目中如出现"偏差会持续/按目前绩效继续"→选典型公式；如出现"偏差是偶然的/已纠正"→选非典型公式

**输出**：工作绩效信息、成本预测、变更请求、项目管理计划更新

## 六、补充财务概念（选择题常考）

|     |     |
| --- | --- |
| 概念  | 说明  |
| **沉没成本** | 已经花掉的钱，决策时**不应考虑** |
| **机会成本** | 选择A放弃B，B的收益就是机会成本 |
| **直接成本** | 项目内成本，如人员工资 |
| **间接成本** | 多个项目分摊，如水电费、房租 |
| **固定成本** | 不随工作量变化，如设备采购 |
| **可变成本** | 随工作量变化，如耗材 |
| **全生命周期成本** | 项目实施成本 + 运营成本 + 报废处理成本 |
| **净现值(NPV)** | 未来现金流的现值总和，NPV>0的项目可行，越大越好 |
| **投资回收期** | 收回投资所需时间，越小越好，从项目建设期开始算 |

## 七、考试高频考点速记

1. **成本基准包含应急储备，不包含管理储备**
  
2. **项目预算 = 成本基准 + 管理储备**
  
3. **管理储备动用需走变更流程**
  
4. **ROM精度：-25%**~+75%；确定性估算：-5%~**+10%**
  
5. **EVM公式：CV=EV-AC，SV=EV-PV，CPI=EV/AC，SPI=EV/PV**
  
6. **典型偏差用EAC=BAC/CPI，非典型用EAC=AC+(BAC-EV)=BAC-CV**
  
7. **TCPI越小越好**
  
8. **沉没成本不参与决策**
