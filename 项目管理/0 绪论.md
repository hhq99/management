
# 第一章 引论 知识点总结（PMBOK第六版）
> 第一章是全书的基础，主要建立项目管理的基本概念和框架。考试中直接考察本章定义性内容较多，属于 **必须准确记忆** 的部分。

## 一、PMBOK指南概述
|要点|内容|
| ---- | ---- |
|全称|项目管理知识体系指南（A Guide to the Project Management Body of Knowledge）|
|目的|收录项目管理知识体系中 “普遍公认”的“良好做法”|
|定位|提供项目管理标准和框架、通用词汇，不是具体方法论|
|范围|只讨论单个项目的管理，只讨论项目管理的共性|
|可裁剪性|标准实践中可以加以选择和裁剪|

> 考试提示：重点关注PMBOK指南的定位——它是“指南”而非“方法论”，且只针对单个项目。

## 二、项目（Project）
**定义**：为创造 **独特** 的产品、服务或成果而进行的 **临时性** 工作。

### 三大特性（必考）
|特性|含义|考试要点|
| ---- | ---- | ---- |
|临时性|有明确的起点和终点|⚠️ 临时≠时间短；终点包括目标达成、项目终止、需求不复存在等。项目临时，但产出成果可以长期运营|
|独特性|可交付成果是 **独特** 的，导致不确定性和风险|可交付成果可以是有形的产品，也可以是无形的服务或知识。允许复用模板、存在重复工作，重复元素不会改变成果整体独特性|
|渐进明细|计划随信息增加而持续改进和细化|贯穿整个项目生命周期反复开展|

- 项目的作用：组织 **创造价值和效益** 的主要方式。
- 项目启动背景（哪些情况下批准项目）：市场需求、组织需要（战略机会 / 业务需求）、社会需求、生态影响（环境考虑）、客户要求、技术进步、法律要求。

## 三、项目管理（Project Management）
**定义**：将 **知识、技能、工具与技术** 应用于项目活动，以满足项目要求。

**核心要点**：
1. 通过合理运用和整合 **49个项目管理过程** 实现
2. 49个过程归类于 **五大过程组** ：启动、规划、执行、监控、收尾
3. 需平衡相互制约的多重因素：范围、质量、进度、预算、资源、风险

## 四、项目集（Program）与项目组合（Portfolio）— 高频考点
| |项目集管理|项目组合管理|
| ---- | ---- | ---- |
|定义|相互 **关联** 且被协调管理的项目、子项目集|为实现 **战略目标** 组合在一起管理的项目、项目集和运营工作|
|核心关注|项目间的依赖关系|资源优先分配，与战略目标一致|
|项目间关系|项目间有关联|项目间不一定相关|

层级关系：**项目组合 ⊃ 项目集 ⊃ 项目**

> 考试提示：三者关系是高频考点——项目组合关注 **战略** 和 **资源** ，项目集关注 **依赖关系**。

## 五、项目与运营（Operations）
| |项目|运营|
| ---- | ---- | ---- |
|特性|临时性、独特性|持续性、重复性|
|目标|实现项目目标后结束|维持经营|

相互关系：运营中产生项目需求；项目成果可能回到运营中。

## 六、项目生命周期（Project Life Cycle）
**定义**：项目从 **启动到收尾** 所经历的一系列阶段。

### 开发生命周期类型（五种）
|类型|特点|
| ---- | ---- |
|预测型（瀑布型）|早期确定范围、时间、成本，范围变更需严格管理|
|迭代型|范围早期确定，时间和成本随理解深入定期修改|
|增量型|通过一系列功能迭代渐进增加可交付成果|
|适应型（敏捷型）|变更驱动型|
|混合型|预测型与适应型的组合|

> 项目生命周期 vs 产品生命周期：两者相互独立，产品生命周期可能由项目产生。

## 七、项目阶段（Phase）与项目关口（Gate）
|概念|要点|
| ---- | ---- |
|阶段|一组有逻辑关系的项目活动集合，通常以 **可交付成果的完成** 为结束|
|阶段审查|项目阶段的关键组成部分|
|项目关口|阶段结束时进行，将绩效与计划比较并作出决策|
|关口决策|①停留在当前阶段 ②进入下个阶段 ③整改后进入 ④重复阶段 ⑤结束项目|

## 八、项目管理过程与过程组
|概念|内容|
| ---- | ---- |
|项目管理过程|通过工具与技术将输入转化为输出|
|五大过程组|启动、规划、执行、监控、收尾|
|十大知识领域|整合、范围、进度、成本、质量、资源、沟通、风险、采购、相关方管理|

> 五大过程组 × 十大知识领域 = 49个项目管理过程的矩阵框架。

## 九、项目管理商业文件
主要包括项目 **商业论证**（Business Case）和 **效益管理计划**，用于论证项目的合理性和预期收益。

1. 项目发起人通常负责项目商业论证文件的制定和维护。
2. 项目经理负责提供建议和见解，使项目商业论证、项目管理计划、项目章程和项目效益管理计划中的成功标准相一致，并与组织的目的和目标保持一致。
3. 项目效益管理计划描述了项目实现效益的方式和时间，以及应制定的效益衡量机制。效益管理计划是商业论证、项目章程和项目管理计划的补充性文件。

## 十、PMP核心价值观
责任、尊重、公正与诚实。
