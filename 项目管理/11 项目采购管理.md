### 一、章节概述

项目采购管理包括从项目团队外部采购或获取所需产品、服务或成果的各个过程。注意：本章节在PMP考试中是站在买方（甲方）角度，即项目团队作为采购方。

**本章共3个过程**：

|     |     |     |
| --- | --- | --- |
| 过程  | 过程组 | 核心作用 |
| 12.1 规划采购管理 | 规划  | 记录采购决策、明确采购方法、识别潜在卖方 |
| 12.2 实施采购 | 执行  | 获取卖方应答、选择卖方、授予合同 |
| 12.3 控制采购 | 监控  | 管理采购关系、监督合同绩效、变更纠偏、关闭合同 |

### 二、合同类型（考试绝对重点，高频必考）

PMBOK主要介绍三大类合同：总价合同、成本补偿合同、工料合同。

#### 1. 总价合同（Fixed Price）

适用于范围定义清楚、对采购工作很熟悉、需求明确且不太可能变更的情况。

|     |     |     |
| --- | --- | --- |
| 子类型 | 特点  | 适用场景 |
| **固定总价（FFP）** | 价格一开始确定，不允许改变（除非范围变更） | 最常见的合同类型，买方风险最小 |
| **总价加激励费用（FPIF）** | 允许绩效偏离，设置价格上限，超上限由卖方承担 | 需要激励卖方达成特定目标 |
| **总价加经济价格调整（FPEPA）** | 允许根据通胀等条件变化调整价格 | **卖方履约期跨越多年**的长期合同，合同以不同货币支付价款 |

#### 2. 成本补偿合同（Cost-Reimbursable）

适用于范围在开始时无法准确定义、需要在合同执行期间调整、风险较高的情况。

|     |     |
| --- | --- |
| 子类型 | 特点  |
| **成本加固定费用（CPFF）** | 报销全部合法成本 + 固定费用（按初始成本百分比计列） |
| **成本加激励费用（CPIF）** | 报销成本 + 达成绩效目标时支付激励费用，有成本分摊比例 |
| **成本加奖励费用（CPAF）** | 报销成本 + 买方主观判断决定奖励，通常不允许申诉 |

#### 3. 工料合同（Time and Material, T&M）

**兼具总价和成本补偿特点的混合型合同**。适用于范围相对明确但工程量不易确定、规模不大、需要快速签合同的情况，如扩充人员、聘请专家。

#### ⭐ 合同风险分配（考试高频）

|     |     |     |
| --- | --- | --- |
| 视角  | 风险最小 | 风险最大 |
| **买方** | 固定总价（FFP） | 成本补偿合同 |
| **卖方** | 成本补偿合同 | 固定总价（FFP） |

### 三、12.1 规划采购管理

**定义**：记录项目采购决策、明确采购方法、识别潜在卖方的过程。

**输入**：需求文件、事业环境因素、组织过程资产。

#### 关键工具与技术

|     |     |
| --- | --- |
| 工具  | 说明  |
| **自制或外购分析** | 决定自行开发还是外部采购 |
| **供方选择分析** | 确定选择卖方的方法 |
| **独立估算** | 自行或请外部专家做成本估算，作为评价卖方报价的标杆 |

**供方选择分析的常用方法**：

- **最低成本**：标准化或常规化采购
  
- **仅凭资质**：采购价值小，不值得花费精力
  
- **基于质量或技术方案得分**
  
- **基于质量和成本**
  
- **唯一来源**：只选择特定卖方
  
- **固定预算**：在成本固定基础上选择
  

#### 关键输出

|     |     |
| --- | --- |
| 输出  | 说明  |
| **采购管理计划** | 包含采购活动安排、风险管理事项等 |
| **采购工作说明书（SOW）** | 根据范围基准编制，详细描述拟采购内容 |
| **招标文件** | RFI（信息邀请书）、RFQ（报价邀请书）、RFP（建议邀请书）主要针对项目型采购，关注解决方案 |
| **供方选择标准** | 对卖方建议书评级打分的标准 |
| **自制或外购决策** | 最终决定 |

### 四、12.2 实施采购

**定义**：获取卖方应答、选择卖方并授予合同的过程，即招标、投标、评标、定标的过程。

输入：卖方说明书、事业环境因素、组织过程资产

#### 关键工具与技术

|     |     |
| --- | --- |
| 工具  | 说明  |
| 广告  | 广告是就产品、服务或成果与用户或潜在用户进行的沟通 |
| **投标人会议**（投标前会议） | 在投标前召开，确保所有潜在卖方对采购要求有清楚且一致的理解，公平对待所有投标人 |
| **建议书评估** | 对卖方建议书进行评审，可用加权打分法 |
| **谈判** | 最终签署合同前就条款进行协商 |

#### 关键输出

- **选定的卖方**
  
- **协议（合同）**
  

### 五、12.3 控制采购

**定义**：管理采购关系、监督合同绩效、实施必要的变更和纠偏，以及关闭合同的过程。

输入：协议、采购文档、工作绩效数据、

#### 关键工具与技术

|     |     |
| --- | --- |
| 工具  | 说明  |
| **合同变更控制系统** | 管理采购相关的变更 |
| **采购绩效审查** | 审查卖方工作进展 |
| **检查与审计** | 验证卖方工作过程或可交付成果对合同的遵守程度 |
| **索赔管理** | ⭐ **谈判是解决所有索赔和争议的首选方法** |

**索赔处理优先级**：

> **谈判 → 替代争议解决方法（ADR，如调解、仲裁）→ 诉讼（最后手段）**

#### 关键输出

- **结束的采购**（采购关闭）
  
- **采购关闭的三大条件**：可交付成果全部验收、无未决索赔或发票、所有款项结清
  

### 六、采购文件类型区分（易混淆考点）

|     |     |
| --- | --- |
| 文件  | 用途  |
| **RFI（信息邀请书）** | 征求信息，了解市场 |
| **RFQ（报价邀请书）** | 征求价格报价 |
| **RFP（建议邀请书）** | 征求详细建议方案 |
| **SOW（采购工作说明书）** | 描述采购内容 |

### 七、采购审计（考点）

采购审计是对从规划采购到控制采购的所有采购过程进行结构化审查，目的是找出成功经验与失败教训，供其他项目借鉴。

### 八、考试提示

1. **立场意识**：本章站在买方（甲方） 角度
  
2. **合同选择是最高频考点**：核心是理解三类合同的风险分配逻辑，而非死记名称
  
3. **项目经理无权签署合同**：通常由具备相关职权的人员执行
  
4. **敏捷环境中的采购**：可能与特定卖方协作扩充团队，营造**风险共担式采购模型**
