### 一、章节概述

**项目资源管理**包括识别、获取和管理所需资源以成功完成项目的各个过程。这些过程旨在确保项目经理和团队在正确的时间和地点，使用正确的资源。

项目资源分为两大类：

- **团队资源（人力资源）**：项目团队成员。
  
- **实物资源**：设备、材料、设施、用品等。
  

本章共包含6个过程，分布在三个过程组中：

|     |     |     |
| --- | --- | --- |
| 过程  | 所属过程组 | 核心目标 |
| **9.1 规划资源管理** | 规划  | 制定如何估算、获取、管理和利用资源的指南。 |
| **9.2 估算活动资源** | 规划  | 估算执行项目所需的团队和实物资源的类型与数量。 |
| **9.3 获取资源** | 执行  | 获取项目所需的团队成员、设施、设备、材料等。 |
| **9.4 建设团队** | 执行  | 提高工作能力，促进互动，改善团队氛围，提升绩效。 |
| **9.5 管理团队** | 执行  | 跟踪表现、提供反馈、解决问题并管理团队变更。 |
| **9.6 控制资源** | 监控  | 确保按计划分配实物资源，并监督其实际使用情况。 |

> **考试提示**：建设团队关注团队整体能力的提升；管理团队侧重于处理人的问题（如冲突）和优化个人绩效。管理团队虽在执行过程组，但具有监控的特点，主要管理人有关的变更。控制资源则是管理实物资源的变更。

### 二、六个过程详解（含ITTO）

#### 1. 9.1 规划资源管理 (Plan Resource Management)

- **定义**：定义如何估算、获取、管理和利用团队以及实物资源的过程。
  
- **主要输入**：
  
  - 项目章程
    
  - 项目管理计划（质量管理计划、范围基准）
    
  - 项目文件（项目进度计划、需求文件、风险登记册、相关方登记册等）
    
- **工具与技术**：
  
  - **数据表现**：这是核心工具，包括：
    
    - **层级型**：如组织分解结构（OBS）、资源分解结构（RBS）。
      
    - **责任分配矩阵（RAM）**：展示项目资源在各个工作包中的任务分配。最常用的例子是RACI矩阵（执行、负责、咨询、知情），每项活动只能有一个“A”（负责人）。
      
    - R=执行（Responsible） A=负责（Accountable） C=咨询（Consult） I=知情（Inform）
      
    - **文本型**：用于记录详细的职责描述。
      
  - **组织理论**：研究不同组织结构对资源管理的影响。
    
  - **专家判断、会议**。
    
- **主要输出**：
  
  - **资源管理计划**：项目管理计划的一部分，提供关于如何分类、分配、管理和释放资源的指南。包含角色和职责，以及项目组织图
    
  - **团队章程 (Team Charter)**：为团队创建价值观、共识和工作指南的文件。应由团队共同制定，明确可接受行为，减少误解。
    

> **考试提示**：RACI矩阵是高频考点，牢记其核心规则：每个活动有且只有一个“A”。团队章程和资源管理计划需区分清楚，前者是团队的行为指南，后者是管理方法。

#### 2. 9.2 估算活动资源 (Estimate Activity Resources)

- **定义**：估算执行项目所需的团队资源，以及材料、设备和用品的类型和数量的过程。
  
- **主要输入**：项目文件（资源日历）、事业环境因素和组织过程资产
  
- **工具与技术**：
  
  - **自下而上估算**：先估算每个活动的资源需求，再汇总得出整体需求。
    
  - 数据分析、PMIS（资源管理软件）、会议
    
- **主要输出**：
  
  - **资源需求 (Resource Requirements)**：识别各工作包或活动所需的资源类型和数量。
    
  - **资源分解结构 (RBS)**：资源依类别和类型的层级展现（如人力、材料、设备）。
    
  - **估算依据**。
    

> **考试提示**：区分RBS（资源分解结构） 和OBS（组织分解结构）。RBS是按资源类型分类，OBS是按部门或团队分类。

#### 3. 9.3 获取资源 (Acquire Resources)

- **定义**：获取项目所需的团队成员、设施、设备、材料、用品和其他资源的过程。
  
- **工具与技术**：
  
  - **预分派 (Pre-assignment)**：资源在事先已选定，不由项目经理决定。如：投标承诺、项目章程指定、独有技能。
    
  - **谈判 (Negotiation)**：与职能经理（获普通资源）、其他项目管理团队（争稀缺资源）、外部组织（获特殊资源）谈判。
    
  - **虚拟团队 (Virtual Teams)**：利用技术让在不同地点的团队成员协同工作。
    
  - **多标准决策分析**。
    
- **主要输出**：
  
  - **项目团队派工单**。记录了团队成员及其在项目中的角色职责。
    
  - **实物资源分配单**。
    
  - **资源日历 (Resource Calendar)**：记录资源的工作时间与非工作时间。
    

> **考试提示**：预分派和谈判是高频考点，需明确各自适用场景。资源日历是客观存在的资源可用时间，区别于资源直方图（项目单位时间所需人员数量的主观需求）。

#### 4. 9.4 建设团队 (Develop Team)

- **定义**：提高工作能力，促进团队成员互动，改善团队整体氛围，以提高项目绩效的过程。
  
- **工具与技术**：
  
  - **塔克曼阶梯理论 (Tuckman Ladder)**：团队发展的五个阶段：
    
    - **形成 (Forming)**
      
    - **震荡 (Storming)**
      
    - **规范 (Norming)**：开始协同工作、互相信任
      
    - **成熟 (Performing)**
      
    - **解散 (Adjourning)**
      

```
1.     > 团队可能停滞在某个阶段、跳过某个阶段，或退回到较早阶段。
```

- **集中办公、沟通技术、团队建设、认可与奖励、培训、个人和团队评估**。

- **主要输出**：团队绩效评价、变更请求、事业环境因素更新

> **考试提示**：塔克曼阶梯是必考内容，需记住五个阶段的正确顺序和特点。认可与奖励应奖励团队整体行为，避免“光环效应”（因某方面好就认为其他方面也好）。

#### 5. 9.5 管理团队 (Manage Team)

- **定义**：跟踪团队成员工作表现，提供反馈，解决问题并管理团队变更，以优化项目绩效的过程。
  
- **工具与技术**：
  
  - **冲突管理 (Conflict Management)**：五种解决方法：
    
    - **撤退/回避 (Withdraw/Avoid)**
      
    - **缓和/包容 (Smooth/Accommodate)**：问题未真正解决
      
    - **妥协/调解 (Compromise/Reconcile)**：各方部分满意
      
    - **强迫/命令 (Force/Direct)**：解决紧急问题
      
    - **合作/解决问题 (Collaborate/Problem Solve)**：最佳方式，达成共识
      

```
1.     > 冲突解决步骤：先由团队成员自行解决，若升级则由项目经理协助（私下处理），再升级则用正式程序。
```

- **人际关系与团队技能**（情商、影响力等）、基本规则。

- **主要输入**：项目文件（问题日志）、工作绩效报告。
  
- 冲突来源排序：进度、项目优先级（备注：启动和规划阶段 排序项目相反）
  

> **考试提示**：冲突管理是重中之重，牢记五种方法的名称、特点及“合作/解决问题”是最佳方法。区分建设团队（提升整体）和管理团队（处理个人问题/冲突）。

#### 6. 9.6 控制资源 (Control Resources)

- **定义**：确保按计划为项目分配实物资源，以及根据资源使用计划监督资源实际使用情况，并采取必要纠正措施的过程。
  
- **关注点**：本过程主要针对实物资源（设备、材料等）。
  
- **工具与技术**：数据分析（如趋势分析）、问题解决等。
  
- **主要输出**：工作绩效信息、变更请求等。
  

> **考试提示**：明确控制资源是针对实物资源，而管理团队是针对人力资源，这是考试中常见的区分点。

### 三、关键考点与易混淆概念总结

1. **资源管理计划 vs. 团队章程**：
  
  1. **资源管理计划**：“如何管资源”的方法论。
    
  2. **团队章程**：“团队如何一起工作”的规则和价值观。
    

2. **建设团队 vs. 管理团队**：
  
  1. **建设团队**：提升团队整体能力、氛围和绩效（“搞团建”）。
    
  2. **管理团队**：处理个人绩效、冲突和团队变更（“处理人的问题”）。
    

3. **资源日历 vs. 资源直方图**：
  
  1. **资源日历**：记录资源（人、设备）的可用工作时间，是客观的。
    
  2. **资源直方图**：显示项目在单位时间内需要的人员数量，是主观需求。
    

4. **激励理论**（高频理论题考点）：
  
  1. **马斯洛需求层次理论**：生理 → 安全 → 社交 → 尊重 → 自我实现。
    
  2. **赫兹伯格双因素理论**：
    
        只有激励因素才能够给员工带来满意感；保健因素只能消除员工的不满，但不会带来满意感
    
    - **保健因素**：工资、工作条件等（缺了会不满，有了不一定激励）。
      
    - **激励因素**：成就感、认可、责任等（真正能激励人）。
      
  3. **麦格雷戈X/Y理论**：
    
    - **X理论**：认为人消极、需要被管。
      
    - **Y理论**：认为人积极、可自我驱动。
      

5. **项目经理的角色**：既是领导者又是管理者，需在获取、管理、激励团队方面投入努力。应让团队成员参与规划，以增强其责任感。
