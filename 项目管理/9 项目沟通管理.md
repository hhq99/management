### 一、章节概述

项目沟通管理包括通过开发工件以及执行用于有效交换信息的各种活动，来确保项目及其相关方的信息需求得以满足的各个过程。项目沟通管理由两部分组成：第一部分是制定策略，确保沟通对相关方行之有效；第二部分是执行必要活动，以落实沟通策略。

**核心数据：** 项目经理花费大部分时间（可能高达90% ）在沟通上。沟通能力是项目经理最重要的能力，比技术能力更重要。

本章包含3个过程：

|     |     |     |
| --- | --- | --- |
| 过程  | 所属过程组 | 核心作用 |
| 10.1 规划沟通管理 | 规划过程组 | 编制书面沟通管理计划 |
| 10.2 管理沟通 | 执行过程组 | 生成、收集、发布、存储信息 |
| 10.3 监督沟通 | 监控过程组 | 确保满足信息需求，优化信息传递流程 |

### 二、各过程ITTO详解（考试重点）

#### 10.1 规划沟通管理

**定义：** 基于每个相关方或相关方群体的信息需求、可用的组织资产以及具体项目的需求，为项目沟通活动制定恰当的方法和计划的过程。需在项目生命周期早期开展，并定期审核修改。

**输入：**

- 项目章程（列出主要相关方清单）
  
- 项目管理计划（资源管理计划、相关方参与计划）
  
- 项目文件（需求文件、相关方登记册）
  
- 事业环境因素（组织文化、沟通渠道、地理分布等）
  
- 组织过程资产
  

**工具与技术：**

- 专家判断
  
- 沟通需求分析：确定项目干系人的信息需求
  
- 沟通技术
  
- 沟通渠道：沟通渠道数= N*（N-1）/ 2
  
- 沟通模型
  
- 沟通方法
  
- 人际关系与团队技能
  

**输出：**

- 沟通管理计划

（各种）干系人的沟通需求、发布信息、确认收悉或做出回应（如适用）的时限和频率等等

#### 10.2 管理沟通

**定义：** 确保项目信息及时且恰当地收集、生成、发布、存储、检索、管理、监督和最终处置的过程。

**输入：**

- 项目管理计划
  
- 项目文件
  
- 工作绩效报告
  
- 事业环境因素
  
- 组织过程资产
  

**工具与技术：**

- 沟通技术：有效果的沟通（Effective communication）——沟通使对方能正确理解的信息 有效率的沟通（Efficient communication）——只沟通必要的信息
  
- 项目管理信息系统：用来确保干系人及时便利地获取所需信息
  
- 项目报告：发布给众多的干系人群体
  
- 人际关系与团队技能
  

**输出：**

- 项目沟通记录
  
- 组织过程资产更新
  

#### 10.3 监督沟通

**定义：** 确保满足项目及其相关方的信息需求的过程。

**输入：**

- 项目管理计划
  
- 项目文件
  
- 工作绩效数据
  
- 事业环境因素
  
- 组织过程资产
  

**工具与技术：**

- 专家判断
  
- 项目管理信息系统
  
- 数据表现
  
- 人际关系与团队技能
  
- 会议
  

**输出：**

- 工作绩效信息
  
- 变更请求
  

### 三、核心考点详解

#### 考点1：沟通渠道计算 ⭐⭐⭐（必考）

**公式：** 潜在沟通渠道总量 = n × (n-1) / 2，其中n代表相关方数量。

> **考试陷阱：** 注意审题是“增加了”还是“增加到”——两者计算结果完全不同。

#### 考点2：三种沟通方法 ⭐⭐⭐（高频）

|     |     |     |     |
| --- | --- | --- | --- |
| 沟通方法 | 特点  | 典型场景 | 关键词 |
| **交互式沟通** | 双向或多向信息交换，确保达成共识最有效 | 会议、电话会议、视频会议 | 实时、面对面、讨论 |
| **推式沟通** | 把信息发送给特定接收方，但不确保理解 | 信件、报告、电子邮件 | 特定群体、发送 |
| **拉式沟通** | 接收方自主获取信息 | 门户网站、知识库、共享网盘 | 大量信息、受众广泛 |

> **做题口诀：** 看到“实时、面对面”选互动沟通；看到“特定群体”选推式沟通；看到“大量信息、受众广泛”选拉式沟通。

#### 考点3：沟通维度分类

沟通活动可按多种维度分类：

- **内部 vs 外部**（团队内部 vs 客户、供应商等）
  
- **正式 vs 非正式**（报告、纪要 vs 邮件、日常交流）
  
- **垂直 vs 水平**（上下级 vs 同级）
  
- **书面 vs 口头**
  
- **官方 vs 非官方**（官方一定是正式，非正式一定非官方）
  

#### 考点4：5C原则

**5C 原则是书面沟通的专用原则**。

1. **Clear Purpose** — 目的明确
  
2. **Correct Expression** — 表达正确
  
3. **Concise Expression** — 表达简洁
  
4. **Coherent Logic** — 逻辑连贯
  
5. **Controlling Ideas** — 思路掌控
  

#### 考点5：沟通模型

- **基本模型：** 发送者 → 接收者（线性）
  
- **完整模型：** 发送者 → 接收者 → 反馈（闭环）
  

#### 考点6：沟通技术选择依据

选择沟通技术时考虑：紧迫性、可用性、易用性、项目环境、敏感性等。

#### 考点7：三个过程的辨析 ⭐⭐⭐

|     |     |
| --- | --- |
| 过程  | 一句话记忆 |
| 规划沟通管理 | **制定计划**——编沟通管理计划 |
| 管理沟通 | **执行沟通**——实实在在地开展沟通 |
| 监督沟通 | **监控调整**——监控是否达到计划要求 |

> **易混淆点：** 规划沟通管理输出沟通管理计划；管理沟通输出项目沟通记录；监督沟通输出工作绩效信息和变更请求。

### 四、高频考题关键词速记

根据考试经验，以下关键词快速定位知识点：

|     |     |
| --- | --- |
| 关键词 | 对应知识点 |
| 信息差、沟通不畅、未及时了解信息 | 沟通管理计划问题 |
| 未识别相关方 | 相关方参与计划问题 |
| 不同国家、文化差异、专业术语 | 沟通需考虑文化意识 |
| 提高共识、处理争端 | 交互式沟通 |
| 虚拟团队 | 规划沟通/沟通管理计划 |

### 五、备考提示

1. **ITTO是必考内容**，掌握每个过程的输入、工具技术和输出对考试非常有帮助。
  
2. **沟通管理计划是核心**：所有沟通问题，都应该先回归"沟通管理计划"。
  
3. **区分沟通管理计划与相关方参与计划**：沟通管理计划侧重如何传递信息；相关方参与计划侧重如何引导相关方参与。
  
4. **沟通管理的对象**是沟通的方法、渠道、工具，而不是具体传达哪一条消息。
  
5. 建议用思维导图自行梳理，至少细化到第四层（ITTO具体内容） 。
